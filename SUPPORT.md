# Support

## How to file issues and get help

This project uses **GitHub Issues** to track bugs and feature requests. Please
search the existing issues before filing a new one to avoid duplicates; for a
new problem, open a new Issue with steps to reproduce and relevant logs.

For questions about using the extension, see the [README](README.md), the
[user guide](docs/user-guide.md) and its
[Known Limitations and Workarounds](docs/user-guide.md#known-limitations-and-workarounds)
section, or open an issue in the
[CMSIS Developer Assistant issue tracker](https://github.com/Open-CMSIS-Pack/CMSIS-Developer-Assistant/issues).

For security vulnerabilities, do **not** open a public issue — follow
[SECURITY.md](SECURITY.md) instead.

# User stories

The stories the CMSIS Developer Assistant should serve. Noted on 2026-10-05
and parked; nothing has been derived from them yet (no proposal, issue or
work package).

1. Someone creates a new Zephyr / CMSIS project from scratch for a piece of
   hardware.
2. Someone adds a feature to an existing project.
3. Someone wants to review an existing CMSIS project.
4. Someone adds a new piece of hardware, like a sensor. Only a datasheet exists.
5. Someone adds an AI model.
6. Someone wants to optimize:
    1. performance
    2. efficiency
    3. resources
    4. accuracy
    5. safety
    6. security
7. Someone has a non-public dfp from a Silicon partner and starts a project
8. Someone wants to start with an example.
9. Someone wants to integrate a specific model to a known hardware with no project yet (either from the Arm AI Portal, hugging face or a repo or locally existing pte, python, tflite)

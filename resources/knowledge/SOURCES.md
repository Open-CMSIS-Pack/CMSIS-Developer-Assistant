# Sources of the CMSIS knowledge index

The knowledge index of the CMSIS Developer Assistant (recipe `core`, `core.db` in the extension)
is built from 7205 knowledge units in Markdown, the folders `units/skills`, `units/canonical`,
`units/extracted`, `units/troubleshooting`, `units/cda-skills`, `units/cda-routes`,
`units/docs`, `units/issues` of the cmsis-knowledge-base repository: procedures, rules and
concepts converted from Agent Skills; the message tables of the CMSIS tools with causes and
fixes in own words; documentation of repositories under an open licence; and digests of public
GitHub issues written in own words. Every unit names its origin in its frontmatter: `source`
(repository, commit and file, the skill file, or the URL of the issue), `license` (the SPDX
identifier of the text, or the marker of an own summary) and `mode` (`V`, text taken from the
source; `S`, an own summary with a link). This file lists the sources, what was taken from each,
their licences, and the copyright lines, licence texts and NOTICE texts those licences require.
It is generated by `tools/sources_md.py` from the units, `sources/docs.yml` and
`sources/licenses.yml`; the units are those of commit bff5475d of the knowledge base.
